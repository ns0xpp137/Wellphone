# 第三方组件声明

`libs/` 下的二进制文件均来自第三方开源项目，随仓库分发仅用于构建，许可均为 Apache License 2.0。

## 1. RikkaApps/Shizuku

- 文件：`libs/adbmod.jar`、`libs/adbdex/classes.dex`、`libs/shizuku-api-classes.jar`、`libs/shizuku-api.aar`、`libs/shizuku-aidl-classes.jar`、`libs/shizuku-aidl.aar`、`libs/shizuku-shared.aar`
- 用途：shell 通道与无线调试配对（`AdbPairingClient` / `AdbClient` / `AdbKey` / `PreferenceAdbKeyStore`）
- 来源：https://github.com/RikkaApps/Shizuku
- 说明：`adbmod.jar` 与 `libs/adbdex/classes.dex` 由上述项目的 adb 相关源码编译而成。本项目仅引用其 adb 协议实现，不包含、不分发、不修改其 server 组件（Shizuku 应用与服务端由用户自行安装，或完全不使用）。

## 2. Conscrypt（独立版）

- 文件：`libs/libconscrypt-arm64.so`、`libs/libconscrypt-armv7.so`
- 用途：adb 配对阶段所需的 TLS `exportKeyingMaterial`
- 来源：https://github.com/google/conscrypt

## 3. Kotlin 标准库

- 文件：`libs/kotlin-stdlib.jar`
- 用途：adb 配对模块（Kotlin 实现）的运行时依赖
- 来源：https://github.com/JetBrains/kotlin
